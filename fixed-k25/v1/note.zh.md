# 25 条边长臂蜘蛛树的零可旋转性

> **草稿：简体中文译文，尚未经过语言审校。**

Jordi Gartner 通过 Beedbyte 发布这项工作。

设 S(25^n,1^m) 为一棵蜘蛛树，其中有 n 条各含 25 条边的命名长臂，中心连接 m 个原始单位叶顶点。对于每个 n ≥ 2 和 m ≥ 0，每个实际存在的顶点——中心、每条命名长臂上深度 1 至 25 的所有顶点，以及存在时的每个原始中心叶顶点——都可以在一个优美标号中取值 0。标号可以随选定顶点而不同。

构造结合了 51 个顶点路径的明确优美 alpha 标号和经典 alpha 拼接方法。余部标号补全其余长臂和叶顶点；另有专门构造处理中心、原始叶顶点和长臂端点。

既有研究完整覆盖了路径情形 n = 2、m = 0 和 n = 2、m = 1；Luiz、Campos 和 Richter 的定理 14 处理中心附有一个叶顶点的路径。Shan 和 Zhong 转述了本构造在传递过程中使用的经典 alpha 拼接方法。固定 k=25 的完整结论由项目内部数学核查和一次独立复制源码 Lean 重放支持。有限范围的文献比较尚不能确定早期构造是否已涵盖完整结论，因此历史优先权仍未确定。
