# 固定臂长 23 的蜘蛛树每个顶点

Beedbyte。Jordi Gartner 通过 Beedbyte 发布这项工作。

**翻译草稿 — 尚未经人工语言审校。** 对于每个 `n ≥ 2` 和 `m ≥ 0`，`S(23^n,1^m)` 的每个实际命名顶点都可以分别在某个优美标号中取值 0。这包括中心、每条命名的 23 边长臂上的每个深度，以及每个实际存在的单位叶顶点。不同目标顶点可以使用不同的标号。结论只涉及固定臂长 23；它不声称适用于所有奇数臂长。

证明把 47 顶点的完整中点 α 路径、中心标号为 0 的剩余树，以及已有的 α 拼接方法结合起来。显式证书覆盖了较早的项目构造在这个固定长度上尚未覆盖的深度。`n=2,m=0` 的路径情形可由 Rosa 的路径结果推出，`n=2,m=1` 的中心悬叶情形可由 Luiz–Campos–Richter 的结果推出；Huang–Kotzig–Rosa 拼接法属于经典方法。对于同时要求中点和极值标号条件的情形，尚未完整核查 Cattell 原始路径构造，因此完整结论的全球优先权仍不确定。

早期来源：[Luiz–Campos–Richter，引理 4 与定理 14](https://ic.unicamp.br/~reltech/2017/17-12.pdf)；[Cattell，《Graceful labellings of paths》](https://www.sciencedirect.com/science/article/pii/S0012365X07001215)。第一份文献也转述了更早的路径与拼接结果。
