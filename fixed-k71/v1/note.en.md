# Every named vertex can be zero for the 71-edge-arm family

For every `n ≥ 2` and `m ≥ 0`, each actual vertex of `S(71^n,1^m)` can receive zero in a graceful labeling. The center, every named vertex on every 71-edge arm, and each original center leaf when present are included. A separate labeling may be used for each selected vertex. This result is for fixed arm length 71 and does not establish the same claim for every odd length.

The path cases `n=2,m=0` and `n=2,m=1` have prior coverage. Worldwide priority remains **UNKNOWN**. Internal checks are not external review or peer review.
