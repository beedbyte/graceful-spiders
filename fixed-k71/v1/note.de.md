# Jeder benannte Knoten der Familie mit Armlänge 71 kann die Null erhalten

Für jedes `n ≥ 2` und `m ≥ 0` kann jeder tatsächliche Knoten von `S(71^n,1^m)` in einer anmutigen Beschriftung die Null erhalten. Dazu gehören das Zentrum, jeder benannte Knoten auf jedem Arm mit 71 Kanten und jedes ursprüngliche Blatt am Zentrum, sofern vorhanden. Für jeden ausgewählten Knoten kann eine eigene Beschriftung verwendet werden. Das Ergebnis gilt nur für die feste Armlänge 71 und beweist die Aussage nicht für jede ungerade Länge.

Die Pfadfälle `n=2,m=0` und `n=2,m=1` sind bereits zuvor behandelt worden. Die weltweite Priorität bleibt **UNBEKANNT**. Interne Prüfungen sind keine externe Begutachtung und kein Peer Review.
