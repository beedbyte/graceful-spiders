# 71 边长臂蜘蛛图族中的每个具名顶点都可标为零

对每个 `n ≥ 2` 和 `m ≥ 0`，`S(71^n,1^m)` 的每个实际顶点都可以在某个优美标号中取得零。顶点包括中心、每条具名 71 边长臂上的全部顶点，以及存在时原有的中心叶子。每个选定顶点可以使用不同标号。此结果只针对固定臂长 71，并未证明所有奇数臂长都成立。

路径情形 `n=2,m=0` 和 `n=2,m=1` 已有先前结果。世界范围内的优先权仍为**未知**。项目内部检查不属于外部评审或同行评审。

**贡献与方法。** Jordi Gartner 通过 Beedbyte 发布这项工作。AI 工具协助了有记录的构造与证明工作、Lean 源码和检查器、数学计算、文献核查以及翻译草稿准备。固定 `k=71` 的定理已在 Lean 4.34.0 中证明。独立的复制源码重放在将警告视为错误的设置下重新编译了全部 45 个 Lean 模块。数学组合审查与重放属于项目内部检查，并非外部学术评审。

资料来源：Luiz、Campos 和 Richter 的[2017 年报告](https://ic.unicamp.br/~reltech/2017/17-12.pdf)；Shan 和 Zhong 的[2026 年论文](https://arxiv.org/abs/2605.14295)；Rofa 的[2023 年论文](https://arxiv.org/abs/2312.16235)。
