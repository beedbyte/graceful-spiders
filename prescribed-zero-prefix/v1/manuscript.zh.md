# D8：补齐等臂蜘蛛树可置零深度的空隙

## 精确定理

S(k^n,1^m)是具有一个指定中心、n条各含k条边的长臂及中心处m个附加叶子的树。深度是距中心的实际图距离。优美标号将顶点双射至0,…,N，将实际边的绝对端点差双射至1,…,N，其中N=nk+m。

对每个整数k≥19，令p=⌊(k−3)/2⌋。19≤k≤34时D8(k)=11，35≤k≤52时为27，53≤k≤124时为25+16⌊(k−35)/18⌋。k≥125时写p=61+11a+r，其中a≥0、0≤r≤10，令

```
F8(p)=107+20a+2r;
D8(k)=F8(p).
```

对所有整数n≥2、m≥0、任意选定长臂及每个整数深度2≤d≤D8(k)，均存在将零赋予该指定顶点的优美标号。不同请求可以使用不同标号。奇偶两种臂长、任意叶子数量及n=2,m=0均包含在内。D8≥D7、D8<k且0≤10k−11D8(k)≤261，所以当k沿所有整数增长时D8(k)/k→10/11。由于D8≥D7，先前K7阈值仍充分；本文不声称新的精确D8逆阈值。

## 构造与四个深度的空隙

使用已接受的大小16和17兼容核心。其反射极值对都从深度26开始。前缀长度为2的正值q9/q10/q11组件保持完整的两侧、相邻和、端点及邻域条件。经典反向补值变换后，它们的深度增量分别为16、18、20。所有插入均先于最后一次反射。

基础大小62、64、66、68、70的五个配方给出缺失的108/109、112/113、116/117、120/121、124/125。大小71、剩余类r=10时，旧界为123，新界为127：大小17核心经一个q10和四个q11步骤给出124/125；大小16核心经五个q11步骤给出126/127。只使用上方顶点对会留下空隙；两个对都必需。

每个目标大小写成p=p0+11t，61≤p0≤71。在反射之前再插入t个q11组件，使大小增加11t、两种深度增加20t。因此七个平移配方在每个大小处补齐F7+1至F8的全部深度。已接受的D7命题提供下方前缀。D8补充证明不需要C6追加；这种追加仍属于独立的D7证明。

通用奇偶路径壳的alpha指标与中点标号分别为k−1或k。粘合时，将所有残余标号加A，高侧路径标号再加残余边数Q，完整划分实际蜘蛛树的顶点标号及边差区间。请求H0位置时对完整图作补标号。相邻最大值可以朝向中心或向外；任意选定长臂与空残余情况均包含在内。

新分支满足10k−11D8=73−2r+10ε，ε为0或1，值域53,…,83。旧分支仍在k124处达到全局最大亏差261。因此所有深度合法，极限比例仍为10/11。首次超过D7的是k127/128，从107增至109；k145/146从123增至127。这些改善每增加22个臂长单位重复出现。
