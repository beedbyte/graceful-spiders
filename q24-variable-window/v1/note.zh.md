# 等臂蜘蛛树中逐渐扩大的零标号深度区间

**Beedbyte.** Jordi Gartner 通过 Beedbyte 发布这项工作。

*翻译草稿；尚无人工语言审校记录。*

对每个整数 t≥0，令 k=23+24t。对于每个 n≥2、m≥0、每条命名长臂 a，以及满足 17+20t≤d≤20+22t 的每个深度 d，S(k^n,1^m) 中臂 a 上深度 d 的实际顶点都可以在一个优美标号中取值 0。每个臂-深度目标可以使用各自的标号。该区间包含 4+2t 个深度：k=47 时为 37–42，k=71 时为 57–64。命题仅覆盖这些深度，不涵盖这些臂长下的所有顶点。

构造从两个 47 个顶点的中点 alpha 路径优美标号开始，再以任意顺序使用 q24 的 B2 和 B4 拼接。两种起始零位置给出两个相接或重叠的深度区间，合起来覆盖完整区间。路径标号转移到实际蜘蛛树中选定的两条长臂；余部构造补全其余长臂和原有中心叶顶点上的优美标号。因此，对所有 n≥2 和 m≥0 都得到同一深度范围。

当 t=0 时，该区间包含在此前已证明的 k=23 全顶点情形中。对于每个 t，路径子族 n=2,m=0 和 n=2,m=1 也已由早期路径结果覆盖：Rosa 的路径结果（由 Luiz、Campos 和 Richter 转述），以及他们关于中心附有一个叶顶点的路径的定理 14。证明使用了经典 alpha 拼接方法（Shan 和 Zhong 对其作了转述），将其作为已有构造工具。

方法：AI 工具协助开发了 B2/B4 混合构造和 Lean 证明；Lean 4.34.0 检查冻结的形式化定理。
