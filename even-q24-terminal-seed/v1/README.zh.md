# 末项为 12 的偶数种子给出的条件性零点区间

**Beedbyte · 源码包 v1**

Jordi Gartner 通过 Beedbyte 发布这项工作。简体中文是翻译草稿，尚无记录显示经过人工语言审校。

## 结果

假设一个末项为 12 的偶数种子 `(K0,z0,c)` 满足形式化命题中的有限条件：`K0≥26` 为偶数；`z0≥3` 为奇数且 `z0+2<K0`；偶数下标处的标签构成 `0,…,K0` 的排列，奇数下标处的标签构成 `0,…,K0−1` 的排列，相邻标签和构成 `0,…,2K0−1` 的排列；中点标签为 `K0`，局部标签为 `[1,0,0,2]`，末项为 12。对每个 `t≥0`，令 `K=K0+24t`。对每个整数深度

`K0−z0−1+20t ≤ d ≤ K0−z0+22t`，

在两个指定的新 K 边臂中的任一臂上，都存在一个常规定义下的优美标号，使所选顶点的标签为 0。每个目标顶点使用各自的标号。此结论适用于这样的图：将路径中点与任意有限图 `H` 的指定根 `r` 识别，并且已给定 `H` 的常规优美标号 `g`，满足 `g(r)=0`。`H` 不必是树或连通图，其标号也不必取遍所有可能值。结论不涉及 `H` 的旧顶点，也不声称两个零值能同时实现。

## 具体种子与 D8 衔接

所含种子数据列出 `(K0,z0)=(26,5),(28,9),(30,3)` 三个具体情形。对应区间分别为 `[20+20t,21+22t]`、`[18+20t,19+22t]` 和 `[26+20t,27+22t]`。形式化源码证明了 K28、K30 种子的有效性及相应区间特例。K26 是此前冻结的具体种子记录；本源码范围不把它表述为新证明的定理。仅对 K30，精确的 D8 衔接从 `t=4` 开始；此时两个保证合并为每条新臂上的 `2≤d≤27+22t`，对所有 `t≥4` 成立。本包不声称 K26 或 K28 存在该衔接。

结果以存在符合条件的种子为前提；它不证明每个偶数 `K0` 都存在这种种子，也不涵盖所有深度、所有偶数臂长、旧顶点或同时出现两个零值的单一标号。本文不主张历史优先权。

## 证明、既有构造与核验

种子族复用既有的 q24 B2/B4 插入构件，以及已知的中点 Alpha 路径与带根优美标号图的拼接方法。一般 Alpha 拼接构造来自 Huang–Kotzig–Rosa，并由 [Panpa、Imnang 和 Wasuanankul（2025），定理 2.5](https://onlinelibrary.wiley.com/doi/full/10.1155/jama/5826777) 和 [Shan–Zhong（2026），引理 1](https://arxiv.org/html/2605.14295v2) 明确表述。另见 [Barrientos（2022），*On the generation of alpha graphs*](https://www.jacodesmath.com/index.php/jacodesmath/article/view/194) 及 [Barrientos–Minion（2019），§2.2](https://digitalcommons.georgiasouthern.edu/tag/vol6/iss1/4/)。本包不声称提出了新的通用拼接构造，也不主张历史优先权。
