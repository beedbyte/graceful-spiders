## Exact accepted statement

For every integer t>=1 let K=23+24t, M=2K, d0=20+22t, d1=21+22t. Let H be any finite indexed graph with Q edges, a chosen actual vertex r, and g:V(H)->{0,...,Q}. Require g to be injective, the edge-difference map to be bijective onto 1..Q, and g(r)=0. Form X by adding two separately named K-edge paths at r, retaining every original vertex and edge of H and identifying only their initial vertices with r. For each side left/right and each physical depth d0/d1 there exists a conventional graceful labeling of X giving zero to that actual selected vertex. These are four separate existential witnesses, not a single labeling with four zeros.

No tree, connectedness, bipartiteness, alpha condition on H, or onto-vertex condition on H is required. A conventional graceful residual with a cycle is included. If g is onto 0..Q, the constructed output labeling is onto 0..M+Q; otherwise its missing residual labels remain missing in the middle band. The stronger full vertex-band conclusion holds if and only if g is onto for these constructed labelings. The theorem does not cover old residual target vertices, every new depth, or the new tips. Root maximum g(r)=Q is sufficient after first complementing the residual labels. An interior root label is not silently normalized by translation.

## Universal actual-graph graft proof

Use the disjoint vertex set V(H) union { (left,d),(right,d):1<=d<=K }. Keep all H edges and add r--(s,1) and (s,d-1)--(s,d). This has Q+M indexed edges and exactly the intended two arms, even if H has inner branching, cycles, isolated vertices or an arbitrary indexing of its root. The chosen path orientation is P or its reversal. Its midpoint is identified with the actual r.

Give H vertex v label A+g(v). For each non-midpoint path vertex with original label x use x when x<=A and x+Q when x>A. Both descriptions of the identified midpoint give A because g(r)=0. Injectivity makes r the only residual zero; no other residual vertex collides with the removed path midpoint. The path low vertices have exactly labels 0..A-1, the residual vertices lie injectively in A..A+Q, and the path high vertices have exactly A+Q+1..M+Q. These disjoint sets prove injectivity and bounds for the combined graph. They prove onto only when the middle band is onto. No vertex-count assumption Q+1 is imposed on arbitrary H.

Each H edge retains its original weight; its weight map is bijective onto 1..Q. Every path edge crosses A, including the two root-incident edges, so its weight is its original weight plus Q. Those edges are bijective onto Q+1..Q+M. The two edge sets are disjoint and together bijective onto 1..Q+M. A low-zero target already has zero. A maximum target has label M+Q; complement the entire output labeling by M+Q-f to make that selected vertex zero. This leaves each edge weight at its actual edge unchanged and preserves injection and bounds. Path reversal supplies the other named arm. Q=0 is valid: injectivity into {0} and the chosen root force H to be a singleton, and the construction reduces to the certified path.

Conventional hypotheses also rule out loops and duplicate unordered-endpoint edges because all indexed weights must be positive and distinct. Their use does not depend on explicitly presupposing a tree. The same proof works directly for the indexed-graph interface.

An exhaustive independent literal generator chooses vertex-label subsets of 0..Q containing zero, then one unordered edge of every weight, for Q<=5. It obtains all 260 such indexed labeled residual instances, including disconnected ones, and checks all four grafts at t=1: 1,040 grafts and 102,692 edges. Four additional cases verify root-maximum normalization. These checks do not prove an unbounded result; the proof is the symbolic partition argument above.

Thirteen effective controls reject: omission of the high-side Q shift; omission of complement for a maximum target; complementing only the new arms; wrong target arm; wrong physical depth; omission of an original H edge; false onto status for the triangle; fixed nonzero root with the unmodified formula; translating a nonzero root to fit the midpoint; an alpha residual with prescribed interior root; a graceful midpoint source without the alpha condition; dropping residual injection; and admitting t=0.

Concrete method-specific counterexamples are explicit. For the edge labeled 0,1 rooted at 1, A+g gives a seam discrepancy A versus A+1. Translating by A-1 to force equality puts the other vertex at A-1, colliding with an occupied path low label. Complementing that residual first is a valid repair and is tested, since its root is the maximum. For the alpha path [0,3,1,2] rooted at its label 1, matching translation causes the same low-band collision; its root is interior, not a maximum. Neither example proves graph-level nongracefulness or impossibility of another root-zero labeling.

The graceful four-edge path [0,4,1,3,2] has its physical midpoint label 1, the correct K-1 value for K=2, but is not alpha at that cut. Grafting a one-edge root-zero residual by the fixed shift produces duplicate weight 1 and omits weight 2. This refutes removing the alpha premise from the general midpoint-splice lemma; it is not presented as a q24-family nonexistence theorem. The actual q24 sources satisfy the alpha premise. A residual edge plus a duplicate-zero isolated vertex has the correct edge weight but violates injection; its output collision rejects a weakened vertex premise.
